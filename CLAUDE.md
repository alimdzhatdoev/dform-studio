## Работа с кодом

- Чистый, читаемый, эффективный и поддерживаемый код
- Без оверинжиниринга и лишних абстракций
- Только функциональные компоненты (для React)
- Компоненты маленькие — одна ответственность
- Логика в хуках/утилитах, UI отдельно
- Понятные и единообразные названия
- Перед созданием нового компонента проверь нет ли похожего
- Не дублировать логику — переиспользовать
- Не вносить новые зависимости без явной необходимости
- Всегда анализируй существующую структуру и стиль проекта перед тем как писать код
- Строго следуй архитектуре и паттернам которые уже используются в проекте

## Визуальный стиль

**Если проект уже существует:**
- Проанализируй существующие компоненты, цвета, шрифты, отступы и паттерны
- Строго следуй этой стилистике во всех новых элементах
- Не вноси визуальные изменения если не просят

**Если проект новый:**
- Найди в интернете как выглядят современные сайты или приложения в этой тематике
- Изучи какие цвета, типографику и UI-паттерны используют лидеры в этой нише
- Подбери уникальную палитру под тематику — не шаблонные синий/серый
- Один цвет доминирует (60-70%), один поддерживающий, один акцентный
- Современный дизайн: чистые линии, достаточно воздуха, чёткая иерархия
- Не делай скучно — каждый экран должен выглядеть продуманно и красиво

## Экономия токенов

- Не объясняй что делаешь — просто делай
- Без лишних комментариев и резюме после выполнения
- Если задача понятна — не переспрашивай
- Думай на английском, отвечай на русском

## Проект: Корпоративный сайт дизайн-студии

### Описание
Дипломная работа — корпоративный сайт дизайн-студии с онлайн-заказами и аналитикой.

### Технологии
- **Frontend**: React (JS, без TypeScript), CSS Modules или CSS-переменные
- **Backend**: PHP + JSON-файлы (без базы данных)
- **Запуск**: Apache/локальный PHP-сервер

### Визуальная концепция
- **Фон**: глубокий графит `#0C0C0E` + тёплый оф-вайт `#F4EFE6`
- **Акцент**: живой лимонно-жёлтый `#E8F439`
- **Типографика**: Display-шрифт для заголовков (Syne / Space Grotesk) + Inter для текста
- **Паттерны**: кинетический текст, hover-анимации, scroll-reveal, разбитые сетки

### Структура страниц
1. **Главная** — Hero, счётчики, кейсы preview, услуги preview, CTA
2. **Портфолио** — фильтрация по категориям, карточки проектов, детальный кейс
3. **Услуги** — карточки с ценами и описанием
4. **О студии** — история, команда, ценности, клиенты
5. **Заказ** — многошаговая форма (тип, бриф, бюджет, контакты)
6. **Контакты** — быстрая форма, соцсети
7. **Админ-панель** — аналитика, управление заказами

### Структура проекта
```
/project
  /frontend          ← React-приложение (create-react-app)
    /src
      /components    ← общие компоненты
      /pages         ← страницы
      /hooks         ← кастомные хуки
      /utils         ← утилиты
      /data          ← статичные данные (портфолио, услуги, команда)
  /backend           ← PHP API
    /api             ← эндпоинты
    /data            ← JSON-файлы (заказы, аналитика)
```

### Этапы разработки
1. Структура проекта, роутинг, PHP API-основа
2. Дизайн-система (CSS-переменные, шрифты, базовые компоненты)
3. Публичный сайт (все страницы)
4. Система заказов (форма + PHP сохранение)
5. Админ-панель и аналитика
6. Анимации, адаптив, финальная полировка

### Правила ревью (после каждого этапа)
- Запускать агента для ревью этапа
- При успехе — агент ревью всего проекта
- Исправлять все найденные ошибки перед переходом к следующему этапу
