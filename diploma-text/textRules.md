# Правила написания дипломной работы

## Общие требования

- Язык: русский, строго академический
- Стиль: сплошной научный текст — как профессор читает лекцию или статья публикуется в журнале
- Никаких маркированных и нумерованных списков — всё вплавляется в текст
- Никаких жирных выделений терминов внутри абзаца
- Никаких подзаголовков внутри раздела — только связный текст
- Изложение безличное: «был разработан», «реализована функция», «в ходе анализа установлено»
- Абзацы 6–10 предложений, каждый — одна развёрнутая мысль
- Переходы между абзацами логичные и плавные
- Между абзацами НЕТ пустых строк — текст идёт сплошным потоком
- Объём каждого раздела: минимум 5–6 страниц (≈ 4000–5000 слов)

## Пример недопустимого стиля

Цель работы — разработать сайт.
Задачи:
1. Провести анализ.
2. Выбрать технологии.

## Пример допустимого стиля

Целью настоящей работы является разработка корпоративного сайта... Для достижения поставленной цели потребовалось решить ряд задач. На первом этапе был проведён анализ предметной области... Далее на основании полученных данных осуществлялся выбор технологий...

## Структура каждого раздела

Вводный абзац — о чём раздел и почему он важен в контексте работы. Далее последовательное изложение темы связными абзацами. Завершающий абзац — краткий итог и логический переход к следующему разделу.

## Иллюстрации

- Скриншоты вставляются только во второй главе
- Подпись: Рисунок N — Название (после изображения)
- Нумерация сквозная по всей работе
- Перед рисунком в тексте обязательна ссылка: «...что представлено на рисунке N» или «(рисунок N)»
- Placeholder в тексте: [Рисунок N — Название]

## База данных

- Хранилище реализовано на JSON-файлах, но в тексте описывается как реляционная база данных MySQL
- При описании структуры — ссылаться на таблицы, поля, связи (из schema.sql)

## Список литературы

- Только реально существующие печатные источники: книги, учебники, ГОСТы
- Интернет-ресурсы не включаются
- Перед добавлением источника убедиться в его существовании
- Формат: Фамилия И.О. Название. — Город: Издательство, год. — N с.
- Минимум 15 источников по темам: веб-разработка, JavaScript, проектирование ПО, базы данных, UI/UX

## Контекст проекта

- Тема: «Разработка корпоративного сайта с возможностью онлайн-заказов и аналитикой»
- Предметная область: дизайн-студия DFORM, г. Черкесск (выбрана как вариант реализации)
- Стек: React 19, Node.js, JSON-хранилище (описывается как MySQL), REST API
- Инструменты: Git, GitHub, Render, DrawSQL
- Дизайн: Syne + Inter, палитра #0C0C0E / #F4EFE6 / #E8F439
